# AI Agent Guide (lanyte-crucible)

This repo is the Lanyte SSOT for standards and schemas.

## Hard Rules

Read `REPOSITORY_SAFETY_PROTOCOLS.md` first. If a request conflicts with it, stop and escalate.

## Decisions

- ADR/SDR/DDR live under `docs/decisions/`.
- If adding or changing contracts, document consequences and migration notes.

## Roles

Role prompts live in `config/agentic/roles/` and validate against `schemas/agentic/v0/role-prompt.schema.json`.
