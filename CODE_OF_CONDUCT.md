# Code of Conduct

This project follows the 3leaps Code of Conduct.

See [CODE-OF-CONDUCT.md in 3leaps/oss-policies](https://github.com/3leaps/oss-policies/blob/main/CODE-OF-CONDUCT.md).

## Quick summary

- Be respectful and inclusive
- Focus on constructive feedback
- No harassment or discrimination

## Reporting

Report concerns to **conduct@3leaps.net**.
