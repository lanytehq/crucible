# Lanyte Crucible v0.3.0

Contract release since v0.2.0. It adds the agentic content family, the
classifiers structure it draws on, and a shared rule for secret-shaped
names and values. Existing families and numbered IPC schema files are
unchanged.

Publishing these contracts does not qualify a consumer implementation.
DDR-0002 and ADR-0019 remain Proposed. Tags are signed manually by the
supervisor; CI never signs. Verify the signature on the published tag.

## Added

### Agentic content v0

`schemas/agentic/content/v0/` defines what a seat captures so work can
continue across sessions: identity, charter, week, day, handoff,
decision-note, learned-fact, reference, cred-ref, and blob, with
checkpoint kept in its existing format. An entry is a durable-record/v1
record narrowed to the registered kinds; it adds no fields.

- `config/agentic/content/v0/kinds.json` sets each kind's writer class,
  revision policy, carrier, and classification floor.
- Week and day lists hold plain text or optional goal objects
  (`kinds/common/goal-item.schema.json`). Goal `status` and `priority`
  use the `project-work/v0` values. Order is the effective rank, then
  list position; a rank is a multiple of 1/16 (ADR-0019).
- `semantic-validation.md` lists the rules JSON Schema cannot express.
  `digest-vectors.json` and `sort-vectors.json` pin values every
  implementation must reproduce.
- `make check-content-v0` validates the family. Every negative fixture
  names the rule it must fail, and the gate fails if a declared rule has
  no fixture or self-test.

### Classifiers

`config/classifiers/` holds discrete choice sets in the 3leaps dimension
format: the Lanyte-owned `content-kind` and `week-start` dimensions, and
verbatim, sha256-pinned copies of the 3leaps sensitivity, access-tier,
retention-lifecycle, and volatility dimensions with their meta-schema.
`scripts/vendor-3leaps-contracts.sh` refreshes the vendored files.

### Secret-shaped names and values

`schemas/common/v0/secret-keys.schema.json` owns the member-name and
credential-value patterns families use to keep secrets out of payloads.
`secret-keys.conformance.json` is the table every regex engine must
agree with.

### Decision records

- DDR-0002 Agent content contract family (Proposed).
- ADR-0019 Ordering ranks on a binary grid (Proposed).
