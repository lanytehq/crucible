# Lanyte Crucible v0.1.0

**First public-track release of Lanyte Crucible.** GitHub slug
[`lanytehq/crucible`](https://github.com/lanytehq/crucible). Display name
remains **Lanyte Crucible**. The tag is signed manually by the supervisor
per the release-signing manual baseline policy
(`docs/policies/release-signing-manual-baseline-policy.md`); CI never
signs.

## Overview

`v0.1.0` is a structure and identity release. It does not add or bump a
schema family. Contract surfaces at this tag match `v0.0.1`, with public
docs, community files, and indexes brought in line with the renamed
repository.

## Highlights

- GitHub slug and in-repo path strings are `lanytehq/crucible`.
- Public docs omit operator layout, chat-host, and internal planning
  identifiers.
- README maps the three sibling crucibles (`3leaps`, `lanytehq`,
  `fulmenhq`) and states that the operating role catalog is
  `3leaps/crucible`.
- Community health files ship with `LIFECYCLE_PHASE=alpha`. Split
  license is unchanged.
- ADR and IPC indexes match files on disk. Channel 260 (chanvoy) is in
  the bootstrap list.

## Compatibility

No JSON Schema files change in this release. Consumers already pinning
`v0.0.1` should re-pin to `v0.1.0` for the public clone path. Role YAML
slug strings in this tree are unchanged this release.
