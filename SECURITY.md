# Security Policy

## Reporting a vulnerability

To report a security vulnerability in this repository, email
**security@3leaps.net**.

Do not open a public GitHub issue for security vulnerabilities.

## Response timeline

We aim to acknowledge reports within 48 hours and provide an initial assessment
within 7 days.

## Scope

This repository contains documentation, specifications, and JSON Schema
contracts — not a signer, runtime, or shipped binary. Security concerns are
most likely to involve:

- Incorrect security guidance in documentation or policies
- Schema or fixture patterns that would be unsafe if implemented as written

For complete security and key-handling policy, see
[SECURITY.md in 3leaps/oss-policies](https://github.com/3leaps/oss-policies/blob/main/SECURITY.md)
and the keys material linked from that document.
